---
title: pgFSM
description: A framework for running versioned finite state machines inside PostgreSQL.
---

pgFSM is a framework for running versioned finite state machines inside
PostgreSQL. State machines are defined once as a JSON schema, compiled into
the database, and then driven forward by sending events through SQL
functions — PostgreSQL is the source of truth for every state, transition,
guard, and event in the system.

An out-of-band worker fleet drives instances forward without the database (or
any HTTP API) ever blocking on worker lifecycle: sync operation logic
(actions, guards, delays) runs inline, while async operation logic (actors)
is dispatched to polyglot (TypeScript/Python/Rust/Go) workers through an
Activity Gateway.
