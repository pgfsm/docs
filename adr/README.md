# Architecture Decision Records

This directory holds ADRs — short documents that record a significant
architectural decision, the context that drove it, and its consequences.

Add a new one by copying [`TEMPLATE.md`](TEMPLATE.md) to `adr-NNN-short-slug.md`
(next free number).

Write one when a decision is expensive to reverse, affects multiple packages, or
a future contributor would otherwise ask "why is it built this way?". Skip it
for anything easily changed later.
